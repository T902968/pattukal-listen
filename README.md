# 🎵 Paattukal

### A clean, modern Android music experience.

**Discover music. Build your library. Listen your way.**

---

## About

**Paattukal** is an Android music app focused on a simple, premium listening experience.

The project is being redesigned around a modern **liquid-glass / depth-inspired interface**, while keeping the existing music and playback foundation intact.

### Design direction

- ✦ Premium, modern visual language
- ✦ Liquid-glass inspired surfaces
- ✦ Album-art ambient lighting
- ✦ Smooth transitions and lightweight animations
- ✦ Clean Home, Search, Library and Player experiences
- ✦ Personalised appearance and theme controls
- ✦ Designed to stay responsive on lower-end devices

---

## ✨ Planned Experience

### Home
A redesigned discovery space for albums, playlists, recommendations and recently played music.

### Search
A clean music-search experience with the existing search and playback functionality preserved.

### Library
One place for:

- Songs
- Albums
- Artists
- Playlists
- Local music

### Now Playing
A premium player experience with:

- Album artwork focus
- Ambient artwork lighting
- Modern playback controls
- Queue and playback controls

### Appearance
Customisation for the visual experience, including theme and appearance options.

## 🛠️ Building

Paattukal is an Android project built with Kotlin and Jetpack Compose.

### FOSS debug APK

```bash
./gradlew assembleUniversalFossDebug
```

The repository also includes GitHub Actions for automated Android builds.

## ⚖️ Open Source & Attribution

Paattukal is based on open-source work from the **Echo Music** project. The existing music engine and playback foundation are derived from Echo Music, while the Paattukal interface and branding are being redesigned separately.
