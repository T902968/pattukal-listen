# Icons

Place the following PNG icons here for full PWA + iOS support:

- `icon-16.png` (16×16)
- `icon-32.png` (32×32)
- `icon-180.png` (180×180) – used as apple-touch-icon
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- `icon-192-maskable.png` (192×192, maskable)
- `icon-512-maskable.png` (512×512, maskable)

Recommended: use the Pattukal logo / headphones symbol on a dark (#090914) or gradient violet-cyan background.

Until real icons are added, the PWA still works; iOS will fall back to a screenshot of the page.
